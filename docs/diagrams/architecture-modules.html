模块协作：消费方定义接口，组合根注入提供方

模块之间不互相 import：消费方定义窄接口，组合根注入提供方。需要翻译错误时由 internal/app/adapters_*.go 包一层（ProductLookup、StockReserver）；签名正好吻合时直接注入（order 的 Service 和 EventLedger）。唯一允许的跨模块 import 是对方的 events 包。fulfillment 没有自己的表，写入都经 order、product 落到它们登记的表里。user 的 user_deleted 目前由 user 自己消费；以后持有用户数据的模块提供 UserDataCleaner，在组合根接上。
